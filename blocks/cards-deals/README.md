# cards-deals

Custom **cards** block. Purpose: dated, expiring deal list with search, Category/Brand facets and sorting.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per deal, 1 cell: H3 title; '<N> Redemption Limit'; 'Valid through MM/DD/YYYY'; '$<amount> OFF'; last line 'Category: <names, comma separated> | Brand: <brand> | Starts: MM/DD/YYYY' (Brand and Starts optional).
