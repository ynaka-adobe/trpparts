# cards-video

Custom **cards** block. Purpose: video cards that open a video player in a modal.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per card; cell 1 = video thumbnail image, cell 2 = title paragraph + Watch Video link (YouTube or Vimeo URL).

## Supported variations

No variations.
