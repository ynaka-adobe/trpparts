# cards-resources

Custom **cards** block. Purpose: searchable, faceted, paginated list of downloadable documents and videos.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per resource, 2 cells; cell 1 = thumbnail image (optional); cell 2 = H2 title linked to the PDF or YouTube URL, optional description paragraph, 'Download' or 'Watch Video' link paragraph, last paragraph 'Type: <type> | Brand: <brand>'.

## Supported variations

No variations.
