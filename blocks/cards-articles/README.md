# cards-articles

Custom **cards** block. Purpose: short list of recent articles or press releases linking to their detail pages.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per item (newest first); cell 1 = thumbnail image (optionally wrapped in a link to the detail page); cell 2 = H3 with the title linked to the detail page, a date paragraph, a teaser paragraph ending with a READ MORE link to the same page.

## Supported variations

No variations.
