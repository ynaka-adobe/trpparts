# cards-member-offers

Custom **cards** block. Purpose: teaser of a few current, time-limited membership offers.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per offer; cell 1 = offer image (alt = product name); cell 2 = three paragraphs: the amount ("<sup>$</sup>3.00 OFF"), the product title, and "Valid until M/D/YYYY".

No variations.
