# cards-downloads

Custom **cards** block. Purpose: downloadable images (wallpapers, calendars) with one link per size.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per downloadable; cell 1 = image; cell 2 = title paragraph, then one paragraph per format: the label text followed by its size links (e.g. Desktop 1920x1080 1024x768).

## Supported variations

No variations.
